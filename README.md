# excel-powerbi-sales-automation
Full-stack + Data -> Automated sales analysis system that integrates Excel (VBA), a Python backend with Django, and Power BI for visualization.

## Objective
Simulate sales and automate processing

## Features
- Data cleansing
- Macros and scripts (VBA | Python)
- Report generation automatization
- Dashboard Power BI Visualization
- Engineering
  - Monthly sales
  - Top products
  - KPIs (revenue, growth, etc.)
  - Modern UI/UX
- Simulate a real system

## Project architecture
```
Excel (VBA)
   ↓ (genera / limpia datos)
CSV / JSON
   ↓
Backend (Django REST API)
   ↓
Power BI (consume API o CSV)
```

## Tech Stack
Excel + VBA → Automatización
Python → Lógica / procesamiento
Django → Backend profesional
API REST → Integración
Power BI → Visualización
